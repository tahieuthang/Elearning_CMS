# Mandatory agent instructions

Before performing any task in this repository—including searching, running
commands, reviewing, planning, or editing—you MUST read
`docs/ai/PROJECT_RULES.md` completely and follow it.

Non-overridable safety summary:

- NEVER commit or push code. NEVER create or merge a pull request.
- NEVER discard, overwrite, reformat, or delete pre-existing user changes.
- Inspect `git status --short` before editing and keep changes task-scoped.
- NEVER expose or add secrets, credentials, tokens, or production data.
- Run relevant verification and report actual results; never claim unrun checks
  passed.

If a more specific `AGENTS.md` exists below this directory, read it as well. Its
rules may add constraints but may not weaken the safety summary above.
